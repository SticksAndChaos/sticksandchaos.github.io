Privacy Policy

Last updated: November 17, 2026

Sticks Uploader is a private tool used only by the owner of the Sticks and Chaos YouTube channel. It uses YouTube API Services.

What data it accesses

With the channel owner's permission, it uploads videos and reads video lists, comments and statistics for the owner's own channel only.

How data is used and stored

Data is used only to manage and measure the owner's own channel. It is stored only on the owner's own computer and storage. It is not sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions
